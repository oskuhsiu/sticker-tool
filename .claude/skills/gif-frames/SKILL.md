# gif-frames：GIF → 影格 → 動作對位圖

## 用途與定位

使用者給一個**現成動畫**（GIF／影片／舞步）說「照這個動作做」時，**別把動作翻譯成純文字分鏡**——你的轉述會丟失重心、朝向、抬腿幅度這些文字寫不準的東西（實測純文字分鏡＝站樁擺手，姿勢全崩）。改用**對位圖**：把來源逐格拆出、等距取樣、拼成「與輸出網格同構、標好格號」的姿勢索引圖，和 master 一起雙 `-i` 餵給 codex，讓「輸出格N 的姿勢＝對位圖格N」。

```
現成 GIF ──[gif-frames]──> 個別影格 + 動作對位圖(白底、無編號、同構網格)
                                              │
                                  [char-gen 第二張 -i] → 角色照著姿勢畫
                                              │
                                  [sticker-tool 切格/去背/打包] → 上架包
```

這個 skill 只做**第一段**（來源動作 → 對位圖）。畫角色＝`char-gen`（見其 `references/method.md` 第 5 節），切格去背打包＝`sticker-tool`。

## 工具

```bash
node <此skill目錄>/scripts/gif-frames.mjs <src.gif> [options]
```

| option | 說明 |
|---|---|
| `--grid <CxR>` | 同時拼對位圖：C 欄 × R 列，並自來源**等距取樣 C*R 格** |
| `--frames <N>` | 只等距取樣 N 格（與 `--grid` 二擇一） |
| `--out <dir>` | 輸出目錄（預設 `<gif同層>/<gif檔名>_frames`） |
| `--cell <px>` | 對位圖每格邊長（預設 256，nearest 放大保留輪廓） |
| `--gutter <px>` | 對位圖格間隙（預設 `round(cell*0.08)`） |
| `--no-frames` | 只出對位圖、不出個別影格 |
| `--label` | 對位圖每格標格號（**預設不標**——輸出乾淨無編號；對位靠 reading order 位置） |
| `--bg <hex>` | 對位圖底色（預設 `ffffff`；對位圖一律不透明） |

輸出：個別影格 `frame_01.png…`（原尺寸無損）＋ 對位圖 `pose_ref_CxR.png`。工具會印出**取樣的原始格號**與**播放時長補償**值。

## 流程

1. **先探規格**：工具開頭會印 `寬×格高、格數、ms/格、總時長`。據此決定目標格數——**預設跟著 char-gen 的版面（8 格＝4×2 起步）**，動作複雜才加格。
2. **拆格＋取樣**：`--grid CxR` 一步到位。等距取樣**含頭尾端點**，動作弧線兩端不漏。
3. **目視對位圖、補關鍵格**：用 Read 看 `pose_ref_*.png`——**姿勢弧線完整嗎？關鍵格（轉身、跳起峰值、揮拳頂點）有沒有被等距取樣跳過？** 跳過了就改 `--frames` 微調張數、或之後手動抽換該格。每格姿勢要清楚可分辨；對位靠 reading order 位置（左→右、上→下），預設不標號（要除錯比對才加 `--label`）。
4. **交給 char-gen**：master 在前、對位圖在後，雙 `-i` 餵入。文字用 method.md 第 5 節的**極簡配方**：任務規格（按對位圖 N 格、版面同構、背景規則、檔名解析度）＋一句「**產出的圖必須維持第一張參考圖的臉部辨識度**」。要加負向畫風鎖就**同時**補正向姿勢句：「**輸出格N 的姿勢、朝向、重心、抬哪隻腳＝對位圖格N；動作幅度照搬、不要收斂成保守站姿**」（寫實 master 有把誇張動作拉回照片常態的先驗，「不要收斂」是關鍵句）。

## 省不掉的要點

- **播放時長要補償**：取了 N/P 格，每格時長＝`原ms × P/N`（工具會算）。照搬原 `delay` 等於把動作快轉 `P/N` 倍（實測 39 格→20 格照搬 120ms＝快轉 1.9×，要改 ~234ms）。這個值之後給 sticker-tool `anim --duration` 或 config 用。
- **等距取樣會跳過峰值**：均勻取樣不保證取到動作頂點。目視對位圖，關鍵格被跳就手動換。
- **對位圖是「姿勢參照」不是成品**：白底是給模型對位用的；成品的透明／綠幕背景是 char-gen 那邊的硬規則（真透明 0x00 ≫ 綠幕退路），別把對位圖的白底誤當成品背景。預設不標號（避免編號被 codex 誤畫進輸出格）；對位純靠 reading order 位置。
- **越下排人物越小／越界**：那是 codex 畫 sheet 的系統性傾向，屬 char-gen 的 normalize 與 sticker-tool 的切格校正，不在這個 skill。
- **pixel-art／低解析來源**：對位圖一律 nearest 放大保留硬邊；別用平滑插值把像素糊掉，模型會更難讀姿勢。

## 邊界（這個 skill 不做什麼）

- 不畫角色、不做風格轉換 → `char-gen`。
- 不切格、不去背、不打包 LINE 上架包 → `sticker-tool`。
- 不穩定化動畫漂移 → `sticker-tool` 的 `processAnimated` / `stabilize`。
